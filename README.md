# BMI Health Guide – Version Final

Ky projekt është një aplikacion web i avancuar me HTML, CSS dhe JavaScript,
i cili ndihmon përdoruesit të llogarisin BMI-në dhe të informohen mbi shëndetin,
dhe ruan të dhënat e përdoruesit përmes localStorage.

## Funksionalitete

- **Homepage informuese** me shprehje motivuese dhe foto background
- **Llogaritje dinamike e BMI**:
  - Input: Pesha dhe Gjatësia
  - Shfaq rezultat + kategori
- **Grafik vizual BMI** me ngjyra sipas kategorisë:
  - Normal → jeshile
  - Mbipesh → e kuqe
  - Nën peshë → portokalli
- **Histori BMI** në localStorage (deri në 5 të fundit)
- **Integrim API publike** për këshilla / ushtrime
- **Dark Mode ON/OFF**
- **Tabela udhëzuese BMI**
- **Buton për kthim tek Homepage**

## Teknologji të përdorura

- HTML
- CSS
- JavaScript
- Chart.js
- Fetch API
- LocalStorage


## Si funksionon

1. Homepage: lexoni informacione për shëndetin dhe BMI.  
2. Klikoni “Llogarit BMI” → hap `calculate.html`.  
3. Plotësoni peshën dhe gjatësinë → rezultat + grafik + histori.  
4. Klikoni “Ndrysho ushtrimin” → API jep një këshillë.  
5. Përdorni Dark Mode për dizajn të errët.  
6. Refresko faqen → BMI-ja dhe ushtrimet ruhet në localStorage.
