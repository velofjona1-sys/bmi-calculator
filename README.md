# BMI Calculator – Sportive Neon

Ky është një **aplikacion web i thjeshtë** për të llogaritur BMI-në (Body Mass Index), me dizajn neon sportive.

**Karakteristikat:**
- 2 faqe:
  1. **Homepage** – për të hyrë në app
  2. **Calculate BMI** – për të shtypur peshën dhe lartësinë dhe për të marrë BMI-në
- Llogaritja bëhet me **JavaScript** pa database
- Stilizim **neon sportive**, i thjeshtë dhe i pastër
- Shfaq kategoria e BMI-së: Underweight, Normal, Overweight, Obese

**Si të përdoret:**
1. Hap `index.html` në browser.  
2. Kliko **Start Calculating** për të shkuar në faqen e BMI.  
3. Shto peshën dhe lartësinë → klik **Calculate**  
4. Rezultati shfaqet menjëherë më poshtë.
